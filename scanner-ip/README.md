# Scanner de IP

Projeto para praticar conceitos de redes utilizando Python.

## Objetivo

Criar um scanner simples capaz de verificar quais hosts estão ativos em uma rede local e quais portas estão abertas em um determinado IP.

## Status

 Em desenvolvimento — projeto ainda não iniciado.

## O que pretendo aprender

- Conceitos de endereçamento IP e portas
- Biblioteca `socket` do Python
- Como verificar se um host/porta está ativo
- Boas práticas de scripts de rede

## Tecnologias

- Python 3
- Biblioteca `socket`
